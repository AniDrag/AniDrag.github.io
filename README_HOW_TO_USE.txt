AniDrag Steam Inspired Portfolio Template

How to use:
1. Put these files in the root of your website folder.
2. Keep your Images folder in the same root folder.
3. Open index.html in a browser.
4. Edit data.js to add or change games, screenshots, project links, and gallery images.

Main pages:
- index.html = home page / storefront front page
- about.html = about me page
- games.html = game library
- game.html?id=sharkbite = reusable project page template
- gallery.html = all photos and art

To add a new game:
1. Add a new object to PORTFOLIO_GAMES in data.js.
2. Give it a unique id, like "my-new-game".
3. Add banner, screenshots, about text, core gameplay, lore, and links.
4. The page will work as game.html?id=my-new-game.

Important:
This is Steam inspired, not a direct copy. Keep your own colors, text, icons, and layout details so it feels like your own portfolio.

Storefront update:
- cv.html presents your existing bio, skills, and project roles, with browser Print / Save as PDF.
- The homepage spotlight uses the first two PORTFOLIO_GAMES entries.
- The game library supports search, tag filters, alphabetical sorting, and reset.
- Project pages include role/toolkit, section navigation, and related projects.
- Existing missing project details, links, and image assets are left for later editing.
