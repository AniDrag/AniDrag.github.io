# AniDrag portfolio

Static HTML, CSS and JavaScript portfolio for GitHub Pages. Open index.html or serve this folder with a static web server. No build step is required.

- index.html: storefront
- games.html and game.html?id=...: game library and project pages
- about.html: personal profile
- cv.html: education, skills, experience and printable CV
- gallery.html: artwork and project screenshots
- data.js: project content, contributions, media and links

The legacy project URLs redirect to the new project pages.

The original site is preserved in _backup/old-site-2026-10-22/ with a SHA-256 manifest. Its .git directory is intentionally excluded; repository history remains in the live checkout. The backup retains the original relative file structure and assets.

Useful material carried over: Saxion CMGT education, contact email, creative tools and version control, presentation experience, project contributions and links, and available screenshots. Old placeholder pack links, conflicting SharkBite descriptions, project years, and the old second-year claim were not carried over.

Missing project descriptions can still be completed in data.js.
